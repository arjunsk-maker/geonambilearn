# GeoNambiLearn — Interactive Geography of India

GeoNambiLearn is a visual geography learning experience for Indian and Tamil Nadu geography, designed around interactive exploration and bilingual learning.

[**View source code on GitHub**](https://github.com/arjunsk-maker/geonambilearn)

> **Live demo:** Not published yet. Add your deployed website URL here when hosting is configured.

## ✨ Project overview

The project explores ways to explain geographical concepts with visual storytelling, interactive maps, and 3D simulations.

## 🧩 Highlights

- Indian and Tamil Nadu geography learning
- Tamil–English friendly learning experience
- Interactive visualizations and 3D exploration
- Topic-focused simulations for concepts such as monsoons and natural hazards
- Modern React + TypeScript frontend

## 🛠️ Tech stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Three.js
- Motion
- Google Gemini API integration

## 🚀 Getting started

### Prerequisites

Install a current Node.js release and npm, or use Bun if you prefer.

### Install dependencies

```bash
npm install
```

### Configure environment

Review `.env.example` and create a local `.env` file with the values needed for your environment. Never commit API keys or other secrets.

### Start the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

## 📁 Repository structure

```text
src/
  components/   Reusable UI components
  data/         Geography content and structured data
  types/        Shared TypeScript types
  App.tsx       Main application
  main.tsx      Frontend entry point
  index.css     Global styles
```

## 🔐 Security notes

- Never commit API keys, access tokens, or private environment values.
- Keep private AI credentials server-side in production.
- Keep `.env.example` free of real secrets.
